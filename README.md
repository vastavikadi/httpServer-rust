## A production-minded, high-performance HTTP/1.1 server in Rust

## What's included
- Non-blocking TCP sockets.
- Linux epoll event loop.
- Efficient connection management.
- Multi-threaded architecture.
- Custom memory management experiments.
- Backpressure and overload protection.
- HTTP parsing and persistent connections.
- Performance profiling and benchmarking.
- An io_uring implementation.
